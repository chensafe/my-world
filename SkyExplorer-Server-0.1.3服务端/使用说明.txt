SkyExplorer 0.1.3 Windows 服务端
Minecraft 1.21.1 / NeoForge 21.1.249 / 64位 Java 21

完整解压到独立文件夹，双击“启动服务端.bat”或“start.bat”。
首次启动生成新 world，本包不含作者存档、玩家信息或测试世界。
关闭时在控制台输入 stop，等待保存完成，不要直接关闭窗口。
从 0.1.2 升级：先停止并备份旧服务端，在新目录解压此包，再迁移原 world、白名单和管理员等数据；保留原世界的 serverconfig，按需要保留原 server.properties 的端口及验证设置。
默认端口25565，正版验证开启，允许飞行，视距6，模拟距离4。
Linux 可使用 sh start.sh；Linux 启动脚本未在本机运行测试。
默认内存2至8GB，在 user_jvm_args.txt 中调整 -Xms/-Xmx。
若启动器找不到Java，把 java_path.txt.example 复制为 java_path.txt，填写 java.exe 的完整路径。
eula.txt 沿用此前 0.1.2 服务端配置；Minecraft EULA：https://aka.ms/MinecraftEULA。

只提供一个版本，包含再见预生成 byepregen 1.1.2.1 和当前客户端启用的 Chunky。
包含 MoreAeroLink 0.10.19、物理收纳器与传送石碑修复、WaystonesSable、
VSS服务端LOD功能、Sable优化补丁、拼豆/TaCZ/农夫乐事兼容、老吴学航空学修复、结构末影守卫/末影傀儡血量修复、配方、战利品、任务书及其美工资源、
枪包、飞艇蓝图、女仆模型、修复后的酒狐成长脚本和猫咪全局战斗配置。
客户端需要同步当前玩法模组；旧 0.1.2 客户端不能直接当作已更新的客户端使用。不要用服务端 mods 覆盖客户端。
Roxy、原生Voxy、光影和纯客户端渲染/操作辅助留在客户端。
旧 Waystones2Waypoints2、VoxyAutoLOD、Voxy WorldGen 及其补丁按当前客户端状态保持停用，没有重新启用。
C2ME配置按当前客户端原样复制，没有调低线程设置。
保留TaCZ导出状态，防止首启恢复已删除的默认枪械/弹药/配件配方。

FTB任务书资源已同步，任务指引和奖励由服务端定义。
戴护目镜和物品动画等客户端功能仍依赖玩家客户端里的相同模组。
未携带个人地图缓存、Voxy缓存、预生成运行任务、日志、备份或Sable面板令牌/证书。
Sable面板启动后会为新服务端生成自己的配置和凭据。
仅保存在某个旧世界里的参数不会凭空迁移到新世界；本包使用当前全局/默认配置。

完成真实独立服务端的新世界启动、save-all flush、stop保存退出以及同世界重启检查。
KubeJS启动和服务端脚本无错误，交付压缩包逐文件核对SHA256。
没有进行真人联机或长期多人压力测试，不能据此保证所有硬件上都没有掉刻。
现有模组仍产生一些非致命旧格式配方、标签及客户端类探测日志；验证进程正常保存退出，详情见外部日志。
