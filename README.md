# my-world

本工作区用于持续改进 SkyExplorer 整合包（当前 v0.1.5）。

> **声明：我们并非该整合包的原作者。** 本仓库仅用于学习、交流与个人改进，整合包版权归原作者所有。如有侵权，请联系删除。

## 目录结构

- `SkyExplorer-0.1.5/client` — v0.1.5 客户端 PCL 懒人包（含 `.minecraft` 与启动器）
- `SkyExplorer-0.1.5/server` — v0.1.5 服务端

## 额外保留模组

客户端与服务端均保留以下四个自有模组：

- Applied Energistics 2 19.2.18
- GuideME 21.1.19
- AE2:Crafting Tree 1.21.1-1.1.1
- Yes Steve Model 2.6.5-neoforge+mc1.21.1

## 用途

- 记录整合包的原始状态，便于回溯
- 对配置、模组和脚本进行修改与调优
- 通过版本提交跟踪每次改进
