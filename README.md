# my-world

本工作区用于持续改进 SkyExplorer 整合包（v0.1.3）。

> **声明：我们并非该整合包的原作者。** 本仓库仅用于学习、交流与个人改进，整合包版权归原作者所有。如有侵权，请联系删除。

## 目录结构

- `SkyExplorer-0.1.3/client` — 整合包客户端
- `SkyExplorer-0.1.3/server` — 整合包服务端

## 用途

- 记录整合包的原始状态，便于回溯
- 对配置、模组和脚本进行修改与调优
- 通过版本提交跟踪每次改进
